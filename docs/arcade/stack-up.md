# Stack Up

Tap to drop the sliding block onto the tower. Only the part that overlaps the block below stays, so the tower narrows as it climbs and the blocks keep speeding up.

<GameFrame slug="stack-up" title="Stack Up, a one-button tower stacking game" hint="Click the game once, then Space works too." />

## Controls

- **Tap, click or Space**: start a run and drop a block.
- **M**: mute. The Options panel has separate music and sound effect volumes and a reduced motion setting.

## Tips

- A drop that lands almost exactly on the block below is a **Perfect**. It keeps the block's full width and scores extra.
- Every five Perfects in a row gives back some of the width you've lost, so a streak is worth more than speed.
- Watch the block, not the tower. Its speed rises every floor and stops climbing at floor 33.

The full rules, the scoring numbers and how the game was built are on the [Stack Up project page](/projects/stack-up).
