# Melon Merge

Drop fruit into a wooden crate. Two of the same kind that touch merge into the next bigger one, from a cherry all the way up to a watermelon. If the pile stays above the line for three seconds, the crate overflows and the game is over.

<GameFrame slug="melon-merge" title="Melon Merge, a fruit merging puzzle game" hint="Click the game once to use the keyboard." />

## Controls

| Input | Action |
|---|---|
| Move the pointer, press and release | Aim, then drop the fruit when you release |
| Touch: drag, then lift | Aim while dragging, drop when you lift your finger |
| `←` / `→`, then `Space` or `↓` | Move the fruit, then drop it |
| `Q` | SHAKE the crate |
| `E` | RIPEN a fruit (pick it with the pointer, or with the arrows and `Space`) |
| `M` | Mute |

## Tips

- Keep the big fruit on one side and build the chain toward it. A watermelon needs a melon next to a melon, and the crate only has room for a few large fruit at once.
- **SHAKE** jolts the whole crate for a moment. Use it when two fruit of the same kind are stuck apart behind a bigger one.
- **RIPEN** grows one fruit by a level in place. Pick one that sits next to a fruit of the next level up, and it merges right away.
- You get a new SHAKE every 800 points and a new RIPEN every 1200, up to three of each.

The full rules, the scoring table and how the game was built are on the [Melon Merge project page](/projects/melon-merge).
