# Bug Squash

Bugs pop up in the cells of a retro terminal. Squash them before they hide, and leave the working features alone. You have three lives, and at 45 seconds the board grows from 3x3 to 4x4.

<GameFrame slug="bug-squash" title="Bug Squash, a retro-terminal whack-a-bug game" hint="Click the game once to use the keyboard." />

## Controls

| Input | Action |
|---|---|
| Tap or click a cell | Squash whatever is in it |
| `1 2 3` / `Q W E` / `A S D` | The cells of the 3x3 board |
| `1 2 3 4` / `Q W E R` / `A S D F` / `Z X C V` | The cells of the 4x4 board |
| `Space` | Start or retry |
| `M` | Mute |

## Tips

- A **hard bug** (bigger, orange, double shell) takes two hits. The first one only cracks it.
- Tapping a **feature** (the cyan gear) or an empty cell costs a life, the same as letting a bug escape. Don't mash: every tap has to be aimed.
- A **golden bug** is worth the most points and gives back a lost life. Letting it go is free, but it resets your combo.
- Keys follow their position on the keyboard, not the letter, so the layout works with any keyboard language.
