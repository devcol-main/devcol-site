# Press Plane

Hold to power the engines and climb. Let go to cut the power and fall. Keep the plane off the obstacles for as long as you can. The only goal is a higher score.

<GameFrame src="https://itch.io/embed-upload/15969002?color=333333" href="https://devcol.itch.io/pressplane" ratio="2 / 3" title="Press Plane, an endless sky-run arcade game" hint="Made in Unity and hosted on itch.io. Click to load." />

## Controls

- **Hold** (mouse button or touch): climb.
- **Release**: descend.

## Tips

- A short tap after a long drop barely slows you down. To turn around, commit to holding. It works more like a throttle than a jump.
- Decide both when to start holding and how long to keep holding.
- The web build is fine for trying the controls. For a real run on a phone, the [Android app on Google Play](https://play.google.com/store/apps/details?id=com.devcol.press_plane) plays better.

How the flight model differs from a tap-to-jump game, and how the game is built, is on the [Press Plane project page](/projects/press-plane).
