# Systems

How PSEUDO plays, one system per page. Each page covers the rules first, then the reasoning behind them.

## The core idea

> **Skill earns you the chance to roll. Luck decides the result.**

Good play (perfect dodges, parries, clean combos) charges dice. Spending a die rolls 2d6, and the result decides how strong the effect is. Every other system either feeds the dice or is changed by them.
